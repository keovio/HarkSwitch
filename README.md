# HarkSwitch

一键切换多个 Hark 账号的 Chrome / Edge 扩展。

## 安装

1. 到 [Releases](https://github.com/keovio/HarkSwitch/releases/latest) 下载 `HarkSwitch.zip` 并解压
2. 浏览器打开 `chrome://extensions`（Edge 是 `edge://extensions`）
3. 打开右上角「开发者模式」→「加载已解压的扩展程序」→ 选解压出的 `HarkSwitch` 文件夹
4. 把工具栏里的 HarkSwitch 图标固定出来

## 使用

1. 在 Hark 网页登录第一个账号 → 点图标 →「保存当前账号」，起个备注名
2. 点「登录新账号」→ 自动退出 → 登录第二个账号 →「保存当前账号」
3. 以后点列表里的账号就能切换，页面自动刷新

鼠标移到账号上可以改名、删除。

## 原理与隐私

- 保存时记录 hark.com 的 cookies 和网页本地存储，切换时写回
- 只存在你自己浏览器的扩展存储里，不存密码，不上传任何服务器
- 每次切走前会自动刷新当前账号的快照，减少登录过期
- 某个账号如果失效（被登出、长期未用），切过去会看到登录页：重新登录后，删掉旧的再「保存当前账号」即可

## 注意

扩展里保存的登录状态等同于登录凭证，别把浏览器给不信任的人用。
